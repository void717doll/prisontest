# Everness textures

Everness by SaKeL. source: [the project's wiki](https://bitbucket.org/minetest_gamers/everness/wiki/Home).

these PNGs are copied unchanged from the supplied Everness distribution.
prisontest resizes them into its 64-pixel terrain atlas and combines grass-side
overlays with dirt while rendering. the bundled files keep their original pixels.
