# Ethereal NG textures

Ethereal NG by TenPlus1. source: [the project's forum topic](https://forum.minetest.net/viewtopic.php?f=11&t=14638).

these PNGs are copied unchanged from the supplied Ethereal NG distribution.
prisontest resizes them into its 64-pixel terrain atlas and combines the grass-side
overlay with dirt while rendering. the bundled files keep their original pixels.
